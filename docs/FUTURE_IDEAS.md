# Future Ideas

## Purpose

This document is a repository for future enhancements, experiments, and product ideas for Versity.

Its purpose is to prevent feature creep during active development while ensuring that valuable ideas are never forgotten.

Adding an idea to this document does **not** mean it will be implemented.

Every idea must later be evaluated against the Version Strategy before development begins.

---

# Evaluation Criteria

Before any idea moves into development, ask:

- Does it support the current version?
- Does it improve the student experience?
- Does it improve business operations?
- Does it follow the Design Bible?
- Is it worth the added complexity?

If the answer is "No", postpone the idea.
