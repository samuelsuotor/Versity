# Development Notes

Every completed sprint should satisfy the following:

- Follows the Design Bible.
- Maintains code quality.
- Improves user experience.
- Is responsive across supported devices.
- Includes documentation updates.
- Includes a Git commit.
- Includes a changelog entry.

A sprint is not considered complete until these conditions have been met.
